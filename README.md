
# 🌌 My Universe

### Explore the Wonders of Our Universe

## 📖 About the Project

**My Universe** is a web development project designed to explore the wonders of our solar system. It provides information about the Sun and planets through individual web pages with an attractive and user-friendly interface.

The project aims to make learning about celestial bodies interesting and accessible through a visually engaging website.

## 🎯 Objectives

- To develop an informative website about our solar system.
- To present astronomical information in an organized manner.
- To create an attractive and user-friendly browsing experience.
- To improve practical skills in web development.
- To encourage curiosity about space and astronomy.

## ✨ Features

- ☀️ **Sun Information:** Explore information about the Sun.
- 🪐 **Planet Exploration:** Learn about the planets in our solar system.
- 🌍 **Individual Web Pages:** Access information about celestial bodies through separate pages.
- 🎨 **Visual Design:** Enjoy a visually appealing website layout.
- 📚 **Educational Content:** Discover interesting facts about space and the solar system.

## 🛠️ Technologies Used

- **HTML5** — Structures the website content.
- **CSS3** — Styles the pages and improves the visual appearance.

## 📂 Project Structure

The project contains HTML pages for celestial bodies, along with CSS files and supporting resources.

Example structure:

│

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Extract the project files if downloaded as a ZIP.
3. Open the project folder.
4. Open `index.html` in your web browser.
5. Explore the website and navigate through its pages.

Alternatively, open the project in Visual Studio Code and use a local development server if required by your implementation.
